Нерешённое помечено строкой **Открыто:** со ссылкой на вопрос в [open_questions_design.md](../open_questions_design.md) или [open_questions_tech.md](../open_questions_tech.md).

Когда открытый вопрос закрывается, ответ записывается в файл вопросов, а решение переносится сюда.
