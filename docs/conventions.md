# Соглашения проекта

## Единицы измерения

**Одна единица длины на весь проект: 1 метр = 1 клетка сетки.** Игра чисто 2D (ответ 115).

| Величина | Единица | Пример |
|---|---|---|
| Длина, позиция, радиус, дальность | метр | радиус удара 1.5 м |
| Скорость | м/с | скорость героя 5 м/с |
| Время, кулдауны | секунда | кулдаун скилла 8 с |
| Уровень рельефа | номер уровня (целое), не длина | обрыв в один уровень |
| Углы | радианы в коде, градусы в данных | |

### Правила

- **Геймплей** (персонажи, снаряды, AI, баланс, данные в `.tres`) хранит значения только в метрах и секундах. Пикселей в нём нет.
- **Пиксели** — это деталь презентации. Они получаются только через `WorldUnits` (`src/core/world_units.gd`): `PIXELS_PER_METER`, `CELL_PIXELS`, `cell_to_pixels`, `meters_to_pixels`.
- **Размер тайла в исходном арте** (`TileTheme.texture_tile_size`) — свойство картинки, а не мира. Рендер масштабирует тайлы так, чтобы клетка на экране занимала `CELL_PIXELS`.
- **Сетка ↔ мир:** `WorldUnits.cell_to_world(cell)` и `world_to_cell(position)`, мир в метрах (`Vector2`).
  - сетка x → мир x (восток);
  - сетка y → мир y (юг);
  - уровень рельефа — не ось мира, а свойство клетки; персонаж на уровне L сталкивается только со стенами уровня L;
  - начало комнаты — верхний левый угол клетки (0, 0).
- **Без «магических» чисел.** Константы вроде `16` или `32` в коде заменяются на `WorldUnits`.
