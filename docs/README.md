## Запуск текущей версии

Приватный репозиторий: [Yultas/WaifuRPG](https://github.com/Yultas/WaifuRPG). Для последних изменений нужна ветка `codex/enemy-ai-implementation-roadmap`; доступ к GitHub должен быть настроен для приватного репозитория. Проверенная версия движка — Godot 4.7.2.

```bash
git clone --branch codex/enemy-ai-implementation-roadmap https://github.com/Yultas/WaifuRPG.git
cd WaifuRPG
godot --headless --editor --import --path . --quit
godot --path .
```

В редакторе можно открыть `project.godot` и нажать F5: главная сцена — `scenes/debug/dungeon_preview.tscn`. После обновления исходников перезапустить запущенную сцену.

- WASD — движение; щелчок ЛКМ — один удар по направлению последнего движения, без автоатаки при удержании.
- ПКМ — скилл, Space — рывок, 1/2/3 — смена героя.
- F — камера за героем, стрелки — переход через дверь, R — новый seed.
- Золотисто-белый взмах и голубое кольцо показывают атаку/скилл, включая промахи. Враги пока могут проходить друг через друга.

Команды headless-проверок — в [roadmap AI](enemy_ai_roadmap.md#проверки-и-фиксация-результатов). Читаемость боя и отрисованный кадр требуют отдельного ручного плейтеста.
